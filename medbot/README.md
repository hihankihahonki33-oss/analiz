# 🏥 Медицинский Telegram-бот

Бот анализирует PDF-файлы с медицинскими анализами и генерирует Excel-отчёт
с подсветкой отклонений, динамикой по времени и выжимкой.

---

## ⚡ Быстрый старт (5 минут)

### 1. Получите токен бота
1. Откройте Telegram, найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя и username бота
4. Скопируйте токен вида `7123456789:AAF...`

### 2. Получите Gemini API Key
1. Зайдите на **aistudio.google.com**
2. Нажмите **Get API key** → **Create API key**
3. Скопируйте ключ вида `AIza...`

### 3. Установите Python
Скачайте с **python.org** (версия 3.10 или новее).

### 4. Установите зависимости
Откройте терминал в папке с ботом и выполните:
```
pip install -r requirements.txt
```

### 5. Заполните .env файл
Откройте файл `.env` и вставьте ваши ключи:
```
TELEGRAM_TOKEN=7123456789:AAF_ваш_токен
GEMINI_API_KEY=AIza_ваш_ключ
```

### 6. Запустите бота
```
python bot.py
```

Готово! Откройте бота в Telegram и отправьте команду /start.

---

## 📋 Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и инструкция |
| `/history` | Показать сохранённые анализы |
| `/report` | Скачать Excel со всеми анализами |
| `/clear` | Удалить всю историю |

**Просто пришлите PDF** — бот сам всё обработает и пришлёт Excel.

## 🔒 Важно о безопасности

- Файл `.env` содержит секретные ключи — **никому не показывайте**
- Не публикуйте `.env` на GitHub или в чатах
- Анализы хранятся локально в файле `data/analyses.db` на вашем компьютере

## ☁️ Запуск в облаке (бесплатно)

Если хотите чтобы бот работал 24/7 без вашего компьютера:

### Railway
1. Зарегистрируйтесь на **railway.app**
2. Создайте новый проект → Deploy from GitHub
3. Загрузите файлы бота на GitHub (без `.env`!)
4. В Railway добавьте переменные окружения: `TELEGRAM_TOKEN` и `GEMINI_API_KEY`
5. Деплой произойдёт автоматически

### Render
1. Зарегистрируйтесь на **render.com**
2. New → Web Service → подключите GitHub репозиторий
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Добавьте Environment Variables в настройках

## ❓ Частые вопросы

**Бот не реагирует на PDF?**
Убедитесь что файл отправлен именно как документ, а не как фото.

**Ошибка "Invalid token"?**
Проверьте токен в `.env` — он должен быть точно скопирован от BotFather.

**Ошибка Gemini API?**
Проверьте ключ на aistudio.google.com — возможно он был отозван.
